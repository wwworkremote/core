# Issue Tracker: GitHub

Issues are tracked using GitHub Issues.

## Reading Issues
- List open issues: `gh issue list --limit 50`
- View a specific issue: `gh issue view <number>`

## Writing Issues
- Create a new issue: `gh issue create --title "<title>" --body "<body>" --label "<labels>"`
- Add a comment: `gh issue comment <number> --body "<body>"`
- Close an issue: `gh issue close <number>`
