## Description

Bring the Chrome extension's job-board capture pipeline to a fully verified state after this session's ATS provider fixes (Greenhouse, Lever, Workday, Ashby, SmartRecruiters), then expand coverage to new job boards using the same verify-before-trust discipline established this session (live-check real postings, prefer stable/semantic DOM hooks and JSON-LD over hashed CSS classes, never guess a selector without checking it against the actual page).
